# Don’t Board Me — Pug Edition

Учебная версия с мопсом на главной странице. Заявки работают в демонстрационном режиме, без отправки компании.

## Публикация

Загрузите всё содержимое этой папки в корень репозитория, включая `.github/`. Ветка — `main`.
В Settings → Pages → Build and deployment → Source выберите GitHub Actions.
Процесс Publish website соберёт и опубликует сайт. Установка пакетов не нужна.

`source-site/`, `src/`, `assets/`, `build.mjs`, `pages.mjs` и `.github/` необходимы. `dist/` создаётся автоматически и в репозиторий не загружается.

Публичная сборка дизайна и материалы оригинала: https://dontboardme.com/. Права на них сохраняются за правообладателями. Модуль главного персонажа находится в `src/pug-motion.js`.
